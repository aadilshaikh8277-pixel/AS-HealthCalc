# AS HealthCalc – BMI Calculator

A simple and user-friendly BMI Calculator website developed using HTML, CSS, and JavaScript.

## Features

- Calculate BMI using weight and height
- Displays BMI value
- Simple and responsive design
- Beginner-friendly project

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Enter your weight in kilograms.
2. Enter your height in centimeters.
3. Click on "Calculate BMI".
4. Your BMI will be displayed.
